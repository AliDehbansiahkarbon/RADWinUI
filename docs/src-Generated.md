# Generated projection

Pascal units generated by `tools/WinMDGen` from the Windows App SDK `.winmd` files. Do not edit them by hand; change the generator and regenerate with `scripts\Generate-Projection.ps1`.

They are committed, so a fresh clone builds without the SDK metadata. Regenerate whenever the generator or the SDK version in `build/WindowsAppSDK.json` changes, and commit the result together with that change.

| Unit | Contents |
| --- | --- |
| `RADWinUI.Abi.pas` | Every enum, struct, interface, delegate and generic interface instance of `Microsoft.UI.*`, `Microsoft.Foundation`, `Microsoft.Graphics.*` and `Windows.Foundation.*`; a Delphi class for each delegate; a record per runtime class for activation and static members |
| `RADWinUI.Xaml.pas` | The `TWinUI*` wrapper classes app code uses: Delphi properties, events and methods for every runtime class in `Microsoft.UI.*` |
| `RADWinUI.Xaml.json` | The type index XamlCodeGen and the designer read: XAML element names, events and editable properties |

How WinRT types map to Pascal: interfaces derive from `IInspectable` and delegates from `IUnknown`, with `safecall` methods, so a failed HRESULT raises an exception. Runtime classes appear as their default interface. Each generic interface instance gets a concrete interface named after its arguments (`IVector_UIElement`) with the IID computed from its signature.
