# Framework

Developer-facing API on top of the generated projection: `TWinUIApplication`, `TWinUIWindow`, control wrappers with Pascal properties, events as method pointers, WinRT errors as Delphi exceptions, and `{Binding}` support.

The API is described in [docs/FRAMEWORK-API.md](FRAMEWORK-API.md). `RADWinUI.CustomControls` lets Delphi classes be XAML elements, `RADWinUI.Controls` holds RADWinUI's own controls built that way, `RADWinUI.TabBars` the six animated tab bars and `RADWinUI.ActionButtons` the six animated buttons, see [docs/CUSTOM-CONTROLS.md](CUSTOM-CONTROLS.md).
