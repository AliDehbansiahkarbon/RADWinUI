# RAD Studio wizard

Design-time package `RADWinUIWizard` (`RADWinUIWizard32` for the 32-bit IDE) with two File > New > Other items:

- Delphi Projects > **RADWinUI Application**: a new project (below).
- Delphi Files > **RADWinUI Window**: another window for the active RADWinUI project. It asks for a unit name, writes `<Name>.xaml` and `<Name>.pas` (class `T<Name>` with a Close button), runs XamlCodeGen and adds the units to the project, the pre-build event already covers every `.xaml` in the folder. Open it from code with `T<Name>.Create.Show`.

RADWinUI Application

The wizard asks for a project name and a parent folder, then writes:

| File | Content |
| --- | --- |
| `<Name>.dpr` | `TWinUIApp.Run(TMainWindow)` |
| `<Name>.dproj` | Win64 only, RADWinUI unit search path, per-monitor DPI, pre-build runs XamlCodeGen on `$(MSBuildProjectDirectory)`, post-build copies the bootstrap DLL to `$(MSBuildProjectDirectory)\$(DCC_ExeOutput)` (created when missing) |
| `MainWindow.xaml`, `MainWindow.pas` | the window (`DataContextType="TMainViewModel"`, a `{Binding}` through the `Format` converter) and its handlers |
| `MainViewModel.pas` | the view model, the window reaches it as the typed `ViewModel` property |
| `MainWindow.Xaml.pas` | generated by XamlCodeGen right away (and before every build) |

and opens the project. No WinUI code runs in the IDE: the wizard writes files and starts `bin\XamlCodeGen.exe`.

## Install in RAD Studio

Open the group of your IDE, Build All, then install its package: `RADWinUI.groupproj` and `RADWinUIWizard.bpl` in the 64-bit IDE, `RADWinUI32.groupproj` and `RADWinUIWizard32.bpl` in the classic 32-bit IDE (one package project and one group per IDE, each package with one platform, so the IDE always offers Install). The `.bpl` is written to `build\packages\<platform>`, where the wizard finds the RADWinUI checkout. To update it later, uninstall it (Component > Install Packages > Remove) and restart the IDE first: a loaded `.bpl` cannot be overwritten.

## Build and test

```powershell
.\scripts\Build-Wizard.ps1     # build\packages\Win32\RADWinUIWizard32.bpl and Win64\RADWinUIWizard.bpl, then Test-WizardPackage.ps1
.\scripts\Test-Wizard.ps1      # outside the IDE: write a project, add a window, MSBuild, run, open and close the window
```

The package finds the RADWinUI checkout from its own location (`<root>\build\packages\<platform>`) or `RADWINUI_ROOT`. Install it with Component > Install Packages from the folder that matches your IDE, the build scripts never install or register anything.
